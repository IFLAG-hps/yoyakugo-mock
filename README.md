# 予約GO 管理画面モック（レスポンシブ対応版）

受付・予約管理システム「予約GO」の管理画面（B画面 ph.3）モックです。
スマートフォン対応の検討用に、既存モックへレスポンシブ対応を追加したものです。

## 確認方法

| 見たいもの | ファイル |
|---|---|
| 全体のトップ | [`index.html`](./index.html) |
| スマホ表示プレビュー（主要7画面を並べて表示） | [`B画面(管理画面)ph.3/sp_preview.html`](./B画面\(管理画面\)ph.3/sp_preview.html) |
| 調整内容の資料（PDF） | [`docs/yoyakugo-admin-sp-responsive.pdf`](./docs/yoyakugo-admin-sp-responsive.pdf) |
| 同資料（Markdown） | [`docs/yoyakugo-admin-sp-responsive.md`](./docs/yoyakugo-admin-sp-responsive.md) |

個別の画面をPCブラウザで見る場合は、DevTools（F12 → Ctrl+Shift+M）で幅を **390px** にしてください。

## 今回追加したファイル

```
B画面(管理画面)ph.3/
  ├ sp.css          … スマホ・タブレット向けの追加スタイル（約480行）
  ├ sp.js           … ハンバーガーの生成と、一覧表へのラベル付与
  ├ sp_preview.html … 確認用のプレビューページ
  └ gate.js         … 公開時のPINゲート（モック閲覧用）
```

各HTMLは `<head>` に読み込みを追記しただけです。

```html
<link href="./sp.css" rel="stylesheet">
<script src="./sp.js" defer></script>
```

**既存の `style.css` と各HTMLの中身は変更していません。**
変更はすべてメディアクエリの中に閉じているため、PC表示（1025px以上）は従来どおりです。

## 主な対応内容

- 左メニューをハンバーガーで開閉する引き出し式に（暗幕タップ／Escで閉じる）
- よく使う画面への下部タブを追加
- 一覧表を「1行＝1カード」のカード表示に
- 入力欄の文字を16px以上に（iOSで入力時にページが拡大されるのを防ぐ）
- ボタンのタップ領域を44px以上に
- モーダルを全画面シートに
- 受付・予約のスケジュールはスマホでは初期表示を「1日」に

詳細と、本実装にあたっての推奨事項は [`docs/yoyakugo-admin-sp-responsive.pdf`](./docs/yoyakugo-admin-sp-responsive.pdf) にまとめています。

## ブレークポイント

| 幅 | 切り替わる内容 |
|---|---|
| 1024px 以下 | 左メニューを引き出しに。本文を全幅に。上部バー・下部タブを表示 |
| 768px 以下 | 一覧表をカード表示に。フォームを1カラムに。モーダルを全画面シートに |

## PINゲートについて

Web上で公開した場合、`gate.js` によってPINコードの入力を求めます。
PINは社内および開発部の担当者にご確認ください。

- ローカルでファイルを直接開いた場合（`file://`）はPINを聞きません
- **これは簡易的な目隠しであり、セキュリティ対策ではありません。** 静的サイトのため、ページのソースを見られれば突破できます。確実に隠したい場合はリポジトリを private にしてください
